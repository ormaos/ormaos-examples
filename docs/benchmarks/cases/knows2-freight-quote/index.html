freight-quote, in knows2

A scheduled job. A scheduled job that asks a carrier's rate API for the freight of tomorrow's shipments and writes one quote per shipment. Source: freight-quote.

Ormaos records and shows what happened inside your Python execution — the runtime context for your agent and for you.

Mean score over every run: none 1.00, raw 1.00, ormaos 1.00, ormaos-values 1.00 (3 runs per arm). Agent: claude-code / claude-opus-5-5.

What happened

The run wrote 26 quotes: 9 from the carrier stand-in's answer and 17 from the contract rate card, after the stand-in refused 17 requests with HTTP 429; the first quote from the rate card is FR-8136. calls_used_today went up by 9, the quotes add up to 114835 cents, and the job printed quotes finished: OK.

The numbers are the oracle's answers to the questions below: oracle/freight-quote.json.

What the agent was given

The folder the execution left, with what the arm adds, and 8 questions in questions.json, written by a model that was not told about Ormaos. The oracle's answers were not in the folder.

QuestionAskedFormatThe oracle's answer
q1How many quote rows did the run write to the quotes table (that is, how many shipments were on the dispatch list it read)?A non-negative integer, e.g. 4226
q2For how many shipments was the written amount_cents the carrier stand-in's answer (an HTTP 200 from /v1/rates), not a price from the contract rate card?A non-negative integer, e.g. 379
q3For how many shipments did the carrier call fail, so that job.price silently fell back to ratecard.rate (the warning was not printed because the log level defaults to ERROR)?A non-negative integer, e.g. 517
q4How many of the run's rate requests did the stand-in refuse with HTTP 429 because the account's calls_used_today had reached calls_per_day?A non-negative integer, e.g. 317
q5What was the shipment_id of the first shipment, in dispatch-list order, whose quote came from the contract rate card instead of the carrier?A single shipment_id string exactly as written in the dispatch list, or the string "none" if every quote came from the carrier"FR-8136"
q6Which shipments were refused by the stand-in with HTTP 422 (chargeable weight above 1000 kg) and therefore quoted from the rate card?A JSON list of shipment_id strings in dispatch-list order, e.g. ["S-104", "S-131"]; [] if none[]
q7By how much did the run increase calls_used_today in data/carrier.json (each request with the right account and quota left counts, including ones then refused with 404 or 422)?A non-negative integer, e.g. 409
q8What was the sum of amount_cents over all quote rows the run wrote to the quotes table?A non-negative integer number of euro cents, e.g. 1234567114835
