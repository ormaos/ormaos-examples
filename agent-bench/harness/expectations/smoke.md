# Expectations: smoke

This is a smoke test of the harness, not a measurement. It is a placeholder
for the expectations a real run needs.

Four runs (knows2, the task order-sync, the four arms, once each,
claude-opus-5-5) are expected to show only that the harness works: the
canary passes, every run ends with a result, an event stream and a grade.
Nothing is expected of the scores, and nothing may be concluded from them.
